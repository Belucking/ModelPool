# ModelPool

ModelPool is a high-performance data management service that optimizes real-time model processing through dynamic auto-scaling and load balancing.

ModelPool is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/ModelPool.git`
2. `cd ModelPool`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
